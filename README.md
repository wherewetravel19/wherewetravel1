# Where we Travel

AI-powered smart trip planning marketing website built with Next.js (App Router).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push this repo to GitHub, then import it on [vercel.com](https://vercel.com) — Vercel
auto-detects Next.js and deploys with zero configuration.

## Pages

- `/` — Home (hero, search, popular destinations, features, budget planner, stats, testimonial)
- `/destinations` — All destinations with search & sort
- `/destinations/[slug]` — Destination detail page
- `/deals` — Flight & hotel deals
- `/plan-trip` — Standalone trip planner page (opens the 3-step modal)
- `/plan-trip/results` — Trip plan summary (reads from localStorage)
- `/events` — Events & festivals guide
- `/blog` — Travel blog
- `/blog/[slug]` — Blog post detail
